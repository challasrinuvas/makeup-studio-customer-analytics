# Makeup Studio Customer Analytics

## 📌 Project Overview

This project analyzes makeup studio customer booking data to understand
customer behavior, service demand, and monthly booking trends.

## 🎯 Objectives

- Analyze customer booking data
- Clean and preprocess the dataset
- Perform Exploratory Data Analysis (EDA)
- Identify popular makeup services
- Analyze monthly booking trends
- Perform SQL-based analysis
- Create useful data visualizations

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- CSV

## 📂 Project Files

- `bookings.csv` – Original dataset
- `bookings_clean.csv` – Cleaned dataset
- `generate_data.py` – Generates booking data
- `clean_data.py` – Cleans the dataset
- `eda_analysis.py` – Exploratory data analysis
- `sql_ana.py` – SQL analysis
- `run_all.py` – Runs the complete project
- `add.py` – Additional Python analysis
- `combined_charts.png` – Combined visualizations
- `monthly_trend.png` – Monthly booking trend
- `service_demand.png` – Service demand visualization
- `requirements.txt` – Required Python libraries

## 📊 Analysis Performed

The project includes:

1. Data generation
